How It Works?

Three simple steps to streamline your user management.

1. Select Target Users

Navigate to Settings > Users. In the list view, select the users you wish to convert to Portal access.

2. Launch Action

Click on the Action button at the top of the list and select "Switch User to Portal".

3. Instant Conversion

The system processes the conversion immediately. You will receive a success notification confirming the number of users converted.
